# 手动测试清单（v0.1.0）

前置：`.\gradlew.bat runServer`，首次需编辑 `run/server/eula.txt` 为 `eula=true`，
`run/server/server.properties` 设 `online-mode=false`；另开两个 `.\gradlew.bat runClient` 连接 localhost。
OP 自己：服务器控制台输入 `op <名字>`。

## 准备

- [ ] /party setarena：反馈中心点坐标
- [ ] /party start（1 人时）：报错"至少需要 2 名玩家"
- [ ] /party start（2 人）：两人被传送进场、背包清空、屏幕出现大字必做任务提示

## 竞技场结构（原 Task 9 GameTest 的验证内容）

- [ ] 地板为石砖，尺寸正确（默认 halfSize=15，即 31×31）
- [ ] 四周围墙 3 格高
- [ ] 北墙内侧中央有石质按钮
- [ ] 东南角附近地面有压力板
- [ ] 4 个装备箱存在且可开，含武器/护甲/食物

## 准备期

- [ ] 玩家间攻击无效（不掉血）
- [ ] 右侧 HUD 列表显示两人名字与命数（♥），自己的禁忌显示 ???，按分数排序

## 对局

- [ ] 完成必做任务：收到"必做任务已完成"提示
- [ ] 触发第一件禁忌：收到含具体内容的警告，HUD 中该玩家禁忌切换为第二件
- [ ] 触发第二件禁忌：出局转旁观，HUD 显示"已出局"
- [ ] PVP 打死对方：对方出局转旁观，自己若抽到"造成伤害"必做则完成
- [ ] 死亡不掉落物品
- [ ] 超时未完成必做者出局，幸存者 +1 并进入下一回合
- [ ] 下一回合所有人重新进场、任务重新分配、分数保留
- [ ] 吃食物/开箱/跳跃/疾跑/蹲下/聊天/破坏/放置/按钮/压力板站 3 秒等触发类型按任务正确判定
- [ ] HUD 颜色按分数变化（0-1 白 / 2-3 黄 / 4 紫 / 5+ 金）

## 胜负与命令

- [ ] 某人到 5 分：宣布胜者，游戏结束
- [ ] /party stop：游戏终止，HUD 清空
- [ ] 掉线玩家视作出局
- [ ] /party score：显示分数榜

## 回归

- [ ] 无 Mod 崩溃日志（run/logs/latest.log 无 ERROR）
