# 手动测试清单（v0.1.0）

前置：`.\gradlew.bat runServer`，首次需编辑 `run/server/eula.txt` 为 `eula=true`，
`run/server/server.properties` 设 `online-mode=false`；另开两个 `.\gradlew.bat runClient` 连接 localhost。
OP 自己：服务器控制台输入 `op <名字>`。

单人快速测试：先把 `run/server/config/partygame.json` 里的 `minPlayers` 改成 `1`
（配置文件在首次跑服务器后自动生成），然后只需一个客户端即可 /party start。
双人联机时改回 2（或保持默认）。

## 准备

- [ ] /party setarena：反馈中心点坐标
- [ ] /party start（人数不足 minPlayers 时）：报错"至少需要 N 名玩家"
- [ ] /party start（2 人）：两人被传送进场、背包清空、屏幕出现大字必做任务提示

## 竞技场结构（原 Task 9 GameTest 的验证内容）

- [ ] 地板为石砖，尺寸正确（默认 halfSize=15，即 31×31）
- [ ] 四周围墙 3 格高
- [ ] 北墙内侧中央有石质按钮
- [ ] 东南角附近地面有压力板
- [ ] 4 个装备箱存在且可开，含武器/护甲/食物

## 准备期

- [ ] 玩家间攻击无效（不掉血）
- [ ] 右侧 HUD 列表显示两人名字与命数（♥），自己的禁忌显示 ???，按分数排序

## 对局

- [ ] 完成必做任务：收到"必做任务已完成"提示
- [ ] 触发第一件禁忌：收到含具体内容的警告，HUD 中该玩家禁忌切换为第二件
- [ ] 触发第二件禁忌：出局转旁观，HUD 显示"已出局"
- [ ] PVP 打死对方：对方出局转旁观，自己若抽到"造成伤害"必做则完成
- [ ] 死亡不掉落物品
- [ ] 超时未完成必做者出局，幸存者 +1 并进入下一回合
- [ ] 下一回合所有人重新进场、任务重新分配、分数保留
- [ ] 吃食物/开箱/跳跃/疾跑/蹲下/聊天/破坏/放置/按钮/压力板站 3 秒等触发类型按任务正确判定
- [ ] HUD 颜色按分数变化（0-1 白 / 2-3 黄 / 4 紫 / 5+ 金）

## 胜负与命令

- [ ] 某人到 5 分：宣布胜者，游戏结束
- [ ] /party stop：游戏终止，HUD 清空
- [ ] 掉线玩家视作出局
- [ ] /party score：显示分数榜

## 回归

- [ ] 无 Mod 崩溃日志（run/logs/latest.log 无 ERROR）

## v2 新增

### 地图
- [ ] /party map save <名字> <半径>：保存自建地图并自动选中
- [ ] /party map list：显示内置程序生成房与自建地图，标注当前
- [ ] /party setarena：自建地图被"搬"进主世界（粘贴），红色羊毛被识别（提示出生点数量）
- [ ] 自建地图出生点不足 minPlayers 时 setarena 报错
- [ ] /party start 后玩家出生在随机分配的羊毛上方，每回合重新随机
- [ ] 程序生成房：地板上出现 8 块红色羊毛出生点
- [ ] /party map choose procedural 切回程序生成房可正常开局
- [ ] /party map remove <名字>：删除地图并回退选中

### HUD
- [ ] 右侧列表从上到下：第几轮 / 阶段+倒计时 / 你的必做 / 玩家行
- [ ] 倒计时每秒递减，阶段切换时正确（准备期→对局→结算）
- [ ] 自己的禁忌显示 ???、剩余命数 ♥ 正确
- [ ] 任何人完成必做：该玩家行打 ✓ 且全服广播
- [ ] 分数排序与颜色分级正确（0-1 白 / 2-3 黄 / 4 紫 / 5+ 金）

### 判定
- [ ] 对局中全员出局 → 广播"全军覆没！本回合无人得分" → 结算后自动进入下一回合
- [ ] 胜利后 /party start 直接开全新一局（分数清零、轮数归 1）
- [ ] 全员掉线仍回 IDLE（不自动开下一回合）

### 配置命令
- [ ] /party config show 显示当前值
- [ ] /party config set minPlayers 1 后重启服务器仍为 1（写回生效）
- [ ] /party tasks disable 某任务后该任务不再被分配；enable 恢复
- [ ] 禁用到禁忌不足 2 个时 /party start 报"任务池不足"

## v2 修复
