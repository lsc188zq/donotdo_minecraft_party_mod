# 建图辅助工具方案

**Goal:** 为自建地图流程提供 4 项辅助：出生点预检查、保存半径可视化、一键平地、引入 WorldEdit。

**Architecture:** 全部为独立工具，不改动游戏状态机。功能 1-3 落在 MapManager + PartyCommand；功能 4 为外部模组引入（无代码）。

**Spec:** `docs/superpowers/specs/2026-08-20-v2-design.md`（设计不变，本方案为开发者工具）

---

### Task 1: 出生点预检查（并入 /party map save）

**方案：** `mapSave` 在保存模板**之前**统计区域内红色羊毛数量；不足 `minPlayers` 时**照常保存**，但在成功反馈里追加醒目警告（"出生点仅 N 个 < minPlayers(M)，setarena 落地会被拒绝"）。不阻断保存（允许先存未完成的施工图）。

**范围：** `PartyCommand.mapSave`（复用 `MapManager.scanSpawns`）。**风险：** 低。**验收标准：** 羊毛不足时保存成功但带警告；足够时无警告。

---

### Task 2: 保存半径可视化

**方案：** 新增两个子命令：

- `/party map preview <半径>`（管理员，玩家执行）：以玩家站位为中心，在**半径外一圈**（±(radius+1)）的 8 个角放**玻璃**标记块（在保存范围之外，不会混进模板），中心点放**荧石**标记；同时在聊天里回显中心坐标。标记位置记录在内存。
- `/party map preview clear`（管理员）：清除玻璃/荧石标记——**仅当该位置当前仍是标记块时才删除**，不误删玩家后来放的其他方块。

**说明：** 保存范围是 ±半径的三维立方（含高度），预览标记只标 X/Z 边界与中心，高度边界靠聊天提示。

**范围：** `MapManager`（标记放置/清除 + 内存记录）、`PartyCommand`。**风险：** 标记方块在服务器重启后位置记录丢失（内存），残留玻璃只能手动拆——可接受（开发者工具）。**验收标准：** preview 后四角与中心可见标记；建图后 clear 只删标记；标记不在保存模板内（角落标记在半径外一圈）。

---

### Task 3: 一键平地

**方案：** `/party map platform <半径>`（管理员，玩家执行）：以玩家站位为中心，清空区域内全部方块与掉落物（复用现有 `clearRegion`/`clearDroppedItems`），在玩家脚下 Y-1 层铺满**石砖**地板，作为搭图基座。

**范围：** `MapManager`（新增 flatten 方法）、`PartyCommand`。**风险：** 破坏性地形操作（管理员权限 + 半径 5-100 限制兜底）。**验收标准：** 执行后区域内只剩一层石砖地板，其余全空。

---

### Task 4: 引入 WorldEdit

**方案：** 从 Modrinth 下载兼容 **NeoForge 1.21.11** 的 WorldEdit 构建，放入 `run/mods/`，启动游戏验证加载。

**范围：** 无代码改动。**风险：** WorldEdit 可能没有匹配 1.21.11/21.11.45 的构建（版本门槛写在 mod 元数据里，不匹配则 ModDev 直接报错）——若找不到兼容版本则如实回报，不影响 Task 1-3。**验收标准：** 启动日志无模组解析错误，游戏中 `/worldedit version` 可用。

---

## 依赖顺序

Task 1-3 相互独立；Task 4 独立。完成后更新 `docs/commands-guide.md` 与手测清单。

## 全局验证

- Task 1-3 完成：`./gradlew compileJava test` 通过 + 用户游戏内手测
- Task 4：启动日志 + 游戏内命令验证
