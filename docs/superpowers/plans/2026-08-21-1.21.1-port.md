# 1.21.1 兼容移植方案

**Goal:** 在 `version/1.21.1` 分支上把 partygame 从 MC 1.21.11 + NeoForge 21.11.45 移植到 MC 1.21.1 + NeoForge 21.1.x，产出可玩的 1.21.1 版 jar。

**Architecture:** 分支双版本（方案 A 变体）。main 冻结 1.21.11 版；本分支完成后由用户决定是否扶正为 main。玩法逻辑与配置结构不变，只做工具链与 API 适配。

---

### Task 1: 工具链切换到 1.21.1

**方案：** 下载 NeoForge 1.21.1（21.1.x）官方 MDK 作基准，对齐本仓库的构建文件（`gradle.properties` 的 minecraft_version/neo_version/mappings 与 `build.gradle` 的插件版本），保留阿里云镜像与现有自定义（client2 运行配置、测试依赖 Gson 等）。首次构建需下载新版本依赖，按 CLAUDE.md 已知坑处理镜像与 0 字节 pom 问题。

**验收标准：** 新工具链能成功加载工程并进入编译阶段——报错全部来自源码 API 差异，而非构建环境/依赖解析问题。

### Task 2: 代码 API 移植（按已知坑反推，逐文件适配）

**预判的 API 差异清单**（实现时逐项用 1.21.1 反编译产物 javap 核对，写错编译期暴露）：

| 21.11.45 现状 | 1.21.1 对应 |
| --- | --- |
| `Identifier` | `ResourceLocation` |
| 无 `displayTitle`（发包实现标题） | `ServerPlayer.displayTitle(...)` 原生存在 |
| `getScoreboardName()` | `GameProfile.getName()` |
| `teleportTo(..., Set<Relative>, ..., setCamera)` | 旧签名 `teleportTo(level, x, y, z, yRot, xRot)` |
| `LivingIncomingDamageEvent` | `LivingHurtEvent` |
| `LivingEvent.LivingJumpEvent` 嵌套类 | 顶层 `LivingJumpEvent` |
| 命令权限 `Commands.hasPermission(Commands.LEVEL_GAMEMASTERS)` | `CommandSourceStack.hasPermission(int)`（op 等级 2） |
| `StructureTemplate.fillFromWorld(..., List<Block>)` | 单参数 `fillFromWorld(..., Block)` |
| `StructureTemplate.load(RegistryAccess, CompoundTag)` / `NbtIo.readCompressed(Path/InputStream, NbtAccounter)` | 1.21.1 旧签名（javap 核对） |
| payload 客户端 handler 注册机制 | 1.21.1 的 `RegisterPayloadHandlersEvent.playToClient` 语义（javap 核对，可能无 ClientNetworkRegistry 独立注册） |
| `NbtIo.readCompressed(InputStream, NbtAccounter)` | 无 accounter 重载 |

**范围：** `src/main/java` 全部文件 + `src/main/templates`（如需）。**风险：** 差异点比清单多——事件名/签名以 javap 为准，编译期暴露。

### Task 3: 编译与测试

**方案：** `./gradlew compileJava test` 全绿；测试类路径无 MC 类的问题同样存在于 1.21.1，测试范围保持一致（纯逻辑 12 个测试）。

### Task 4: 游戏内冒烟测试（用户执行）

**方案：** 1.21.1 版跑单人冒烟：setarena → start → 任务判定 → HUD 显示 → 地图保存/选择 → 退出世界重进状态重置。WorldEdit 需另装 1.21.1 兼容版（dev 辅助，与本体无关）。

**验收标准：** 全部通过；jar 打包含图标与内置地图。

---

## 全局验证

- 每 Task：gradle 输出 + 测试报告
- 最终：1.21.1 jar + 冒烟清单
- 完成后：由用户决定合并/扶正分支

## 实施中发现的额外根因（已解决）

1. **ModDev 2.0.144 与 NeoForge 21.1.x 不兼容**：生成的 dev 启动目标引用 21.1.x 工具链不存在的 `net.neoforged.fml.startup.Client` → 插件降级 `1.0.24`（21.1.x 时代配套版本）；`gameTestServer` 运行配置 1.x 不支持，已移除（项目未用 GameTest）
2. **FML 4.0.43 要求 mods.toml 顶层声明 `modLoader`/`loaderVersion`**（21.11.45 的 FML 不强制）：模板已补顶层字段
3. dev 环境 `run/mods` 里的 1.21.11 版 WorldEdit 与 1.21.1 不兼容，需删除或换 1.21.1 版
4. 源码移植实测比预判少：`LivingIncomingDamageEvent`、嵌套 `LivingJumpEvent`、`NbtAccounter` 重载在 1.21.1 已存在
