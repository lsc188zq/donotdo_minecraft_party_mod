# 玩家状态保存与恢复方案

**Goal:** 游戏不再"伤及"玩家的原始状态：开局前保存每位玩家的位置/背包/血量/游戏模式，游戏结束或 /party stop 后完整恢复；setarena 建场地时把区域内玩家安全移出，防止误伤。

**Architecture:** GameManager 内增加快照表（内存，UUID → 快照），不持久化（服务器重启快照丢失，简单实现）。

---

### Task 1: 开局快照与结束恢复

**方案：**

- `/party start` 时（beginRound 之前），为每位入局玩家保存快照：所在维度与坐标、背包（主栏 + 盔甲 + 副手，NBT 序列化）、游戏模式、血量/饥饿值
- **恢复时机**：游戏正常结束（finishGame）、`/party stop`、全员掉线回 IDLE——对**在线**玩家恢复全部快照内容（传送回原位置、还背包、还原游戏模式与血量）
- **掉线玩家**：快照保留在内存，玩家重连（PlayerLoggedInEvent）时自动恢复
- 回合之间（SCORING → 下一轮）**不恢复**（回合制连续游玩）
- 恢复失败不阻塞游戏：单项失败记警告日志，其余项照常

**范围：** `GameManager`（快照类 + 保存/恢复方法）、`PartyCommand.start/stop`、`GameEventListeners`（重连事件）。**风险：** 1.21.1 背包序列化 API 签名需 javap 核对（`Inventory.save`/`ItemStack.save`）；恢复与"掉线视作出局"的交互——出局玩家在游戏内不恢复，仅游戏结束恢复。

**验收标准：** 开局→游玩→结束后：位置、物品、模式、血量全部还原；/party stop 同样还原；中途掉线重连后物品仍在。

### Task 2: setarena 安全移出

**方案：**

- `setarena` 清空区域**之前**，把区域内（±半径立方）所有在线玩家传送到中心点上方安全高度（重置摔落伤害），避免被清空方块波及或坠入坑中
- 区域重建完成后传送回原位置（若原位置已被新地图占用，则留在安全点）
- 反馈消息中提示"区域将被清空，请确保场地内没有重要建筑"（真正防毁家靠选空旷场地；区域自动备份暂不做，列为可选扩展）

**范围：** `PartyCommand.setArena`。**风险：** 低。**验收标准：** 站区域内执行 setarena，自己与其他区域内玩家被安全移出、无摔落伤害，结束后位置恢复（或留在安全点）。

---

## 已知限制（不在本次范围）

- 快照仅内存，服务器重启即失效（重启时游戏本就回 IDLE，影响小）
- 区域方块级备份（真正的"防毁家"撤销能力）暂不做，如需后续立项
